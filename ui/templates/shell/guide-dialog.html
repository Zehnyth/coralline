From module to registry

Publish guide

Run these commands on your registry host. Set CORALLINE_ADMIN_CREDENTIAL to the admin token printed on first boot.

  1. Create a namespace
    coralline namespace create platform
  2. Mint a scoped token
    coralline token create --name ci-publisher --namespace platform --role publisher

    Save the token shown once as CORALLINE_TOKEN.

  3. Package and publish
    tar -czf module.tar.gz *.tf
curl --fail --request PUT \
  --header "Authorization: Bearer $CORALLINE_TOKEN" \
  --data-binary @module.tar.gz \
  "https://{{.Host}}/v1/modules/platform/network/aws/1.0.0/publish"

    This example uses a POSIX shell. Use a certificate your client trusts.

Already published? Open a module to copy its source and pinned version into your Terraform configuration.
